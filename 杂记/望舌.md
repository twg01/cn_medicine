

# 一 核心概念：舌为什么能望

## 舌与脏腑经络的关系

心开窍于舌，脾连舌本、散舌下，肾挟舌本，肝经络舌本，肺系上连咽喉、与舌根相通。这是舌能反映五脏病变的经络基础。但光背这些经络循行还不够，要理解舌是五脏精气外透的"显示屏"，而且是一块分区显示的显示屏。

## 舌与气血津液的关系

舌体靠气血濡养，所以舌色反映血的盛衰与运行状态。舌苔由胃气蒸化谷气上潮于舌面而成，所以舌苔反映胃气的存亡和脾湿的轻重。舌的润燥反映津液的盈亏。这三条是舌诊的总纲：舌体看血，舌苔看气与湿，润燥看津。

## 舌诊的临床意义

判断正气盛衰、病位深浅、病邪性质、病势进退。这四句话教材上有，但要展开讲：正气盛衰看舌质，病位深浅看舌苔厚薄，病邪性质看苔色与舌质，病势进退看舌象的动态变化。

# 二 五脏与舌的外候（理论衔接层）

这是最容易被忽略的一层。基础理论学过五脏藏神、五脏主五体，但到舌诊时，这些知识要变成"舌面上的地图"。

## 舌面五脏分候

| 舌面部位 | 所属脏腑 | 观察要点 | 临床意义 |
| :--- | :--- | :--- | :--- |
| 舌尖 | 心肺 | 颜色红淡、有无点刺 | 心火盛衰、肺气宣降 |
| 舌中 | 脾胃 | 舌苔厚薄、有无裂纹 | 胃气存亡、脾湿轻重 |
| 舌根 | 肾 | 颜色深浅、有无腻苔 | 肾命精气、下焦湿热 |
| 舌边 | 肝胆 | 颜色红淡、有无瘀斑齿痕 | 肝血盈亏、胆气疏泄 |
| 舌下 | 心肝肾 | 络脉粗细、颜色紫淡 | 瘀血轻重、阴血盛衰 |

## 心主血脉，其华在舌

心主血脉，舌为心之苗。所以舌色是心血状况最直接的反映。心血足，舌色淡红而润；心血虚，舌色淡白；心火盛，舌尖红赤；心血瘀，舌色紫暗。望舌时先看舌色，就是在看心的功能状态。

## 脾主运化，其荣在唇舌

脾为后天之本，舌苔由胃气蒸化而成。所以舌苔是脾胃功能的晴雨表。胃气足，舌苔薄白而润；胃气败，舌苔剥落或无苔；脾湿盛，舌苔厚腻；湿热蕴脾，舌苔黄腻。很多现代人舌中厚腻，直接指向脾的运化失常。

## 肾藏精，舌根反映肾命

舌根属肾。肾精足，舌根淡红而润；肾阴虚，舌根红绛少苔；肾阳虚，舌根淡白胖嫩；下焦湿热，舌根黄腻。很多慢性病人，舌尖舌中还好，舌根一层厚腻苔，说明病已入下焦，肾命受累。

## 肝藏血，舌边反映肝郁

舌边属肝胆。肝血足，舌边淡红柔润；肝郁气滞，舌边偏暗或见瘀点；肝火旺，舌边红赤；肝血虚，舌边淡白瘦薄。现代人压力大，舌边齿痕和舌边偏红是最常见的两种肝系舌象。

## 肺主气，与舌润燥相关

肺主气，司呼吸，通调水道。肺津充足，舌体润泽；肺燥伤津，舌体干燥；肺气不宣，舌体胖大。舌的润燥状态，往往与肺的宣发肃降功能密切相关。

## 胃与舌苔

舌苔虽挂在脾经之下，但直接由胃气所生。胃气蒸化谷气，上潮于舌面，才形成舌苔。所以舌苔是胃气存亡的直接标志，不是脾的独功。

胃气充足，舌苔薄白而润，紧贴舌面，有根。胃气衰败，舌苔剥落，或无苔，或苔浮无根。胃热炽盛，舌苔黄燥，甚至焦黑。胃寒凝滞，舌苔白滑，水滑欲滴。胃阴不足，舌苔少或无苔，舌面干燥。

临床上，一个长期呕吐、不能进食的病人，舌苔突然剥落，舌面光洁如镜，这是胃气将绝的危象。一个暴饮暴食的人，舌苔厚腻腐垢，这是胃中腐浊上泛。望舌时，看到舌苔的变化，心里要同时想到胃气的状态，不能只说脾虚，忘了胃的受纳腐熟。

# 三 临证望舌操作法

舌诊比望神更依赖规范操作。光线不对、姿势不对、顺序不对，都会看错。

## 光线要求

自然光最好。白炽灯偏黄，会让黄苔看不出；LED灯偏白，会让淡白舌显得正常；日光灯偏青，会让红舌显得紫。诊室如果没有自然光，至少要备一盏接近自然光谱的台灯。这是硬件，不能将就。

## 姿势要求

叫病人伸舌，自然伸出，不能用力。用力伸舌，舌色会变红；伸舌时间太长，舌色也会变红。所以要求"伸舌不过三秒"，看一眼，缩回去，再伸再看。病人如果张口呼吸，舌面会干，苔质判断会失真，要让他闭口鼻息。

## 望舌顺序

一步看舌质（颜色、形态、润燥），二步看舌苔（厚薄、颜色、分布），三步看舌态（运动是否灵活），四步看舌下络脉。这个顺序不能乱。因为舌苔会遮盖舌质，先看舌苔容易漏掉舌质的变化。

## 注意事项

饮食染苔：喝牛奶、豆浆后舌苔变白；吃橘子、黄连素后舌苔变黄；抽烟后舌苔变灰黑。药物染苔：抗生素长期用，舌苔变黑或剥落。这些要在问诊时问清楚，否则望舌会误判。

# 四 舌质变化

舌质，又称舌体，是舌的肌肉脉络组织。望舌质主要观察舌色、舌形、舌态、舌下络脉四个方面。舌色反映气血的盛衰与运行情况，舌形反映脏腑的虚实与邪正的盛衰，舌态反映脏腑功能的强弱与经络的通利与否。

## 舌色总表

| 舌色 | 概念 | 主要病机 | 主病 | 现代人体质关联 |
| :--- | :--- | :--- | :--- | :--- |
| 淡白舌 | 舌色较正常浅淡，白色偏多 | 气血两虚、阳虚 | 虚证、寒证 | 长期节食、贫血、过度劳累 |
| 淡红舌 | 正常舌色，红活明润 | 气血调和 | 健康人或病轻 | 理想状态，现代人少见 |
| 红舌 | 舌色较正常红，鲜红 | 热盛、阴虚 | 实热、虚热 | 熬夜、辛辣饮食、更年期 |
| 绛舌 | 舌色深红，暗红 | 热入营血、阴虚火旺 | 温病热入营血、久病阴虚 | 长期慢性炎症、自身免疫病 |
| 紫舌 | 舌色青紫或紫暗 | 血瘀、寒极、热极 | 瘀血、寒极、热毒 | 久坐、心脑血管病、肿瘤 |
| 青舌 | 舌色如皮肤暴露之青色 | 寒凝、瘀血极重 | 阴寒内盛、瘀血重证 | 罕见，危重病人 |

## 各型（节选示例）

淡白舌不是只血虚，还要分淡白而润和淡白而干。淡白而润是阳虚，阳气不能蒸化津液上潮；淡白而干是气血两虚到了严重程度，连津液都化不出来了。现代人减肥过度，很多年轻女孩舌头淡白得像纸，这是气血大亏，不是简单的贫血，是后天之本和先天之精都伤了。

红舌要分实红和虚红。实红是舌红苔黄，整个舌像涂了朱砂，这是实火，清心泻火就行。虚红是舌红少苔或无苔，像煮熟的猪肝，这是阴虚火旺，不能泻火，要滋阴。很多中年人熬夜后舌红，以为是上火，喝凉茶，越喝越虚，因为那是阴虚不是实火。

绛舌是红舌的进一步发展，像猪肝暗红。温病里见绛舌，是热入营血，要清营凉血。内科杂病里见绛舌，多是久病阴虚到了极点，肾水不能上济心火。这种舌象，滋阴要重，填精要缓，不能急。

## 舌形总表

| 舌形 | 概念 | 主要病机 | 主病 |
| :--- | :--- | :--- | :--- |
| 老舌 | 舌体纹理粗糙，坚敛苍老 | 实证 | 热盛、气滞、血瘀 |
| 嫩舌 | 舌体纹理细腻，浮胖娇嫩 | 虚证 | 气血两虚、阳虚水停 |
| 胖大舌 | 舌体胖大，边有齿痕 | 脾虚湿盛、肾虚水泛 | 脾虚、湿困、肾虚 |
| 瘦薄舌 | 舌体瘦薄而色淡 | 气血两虚、阴虚 | 气血虚、阴虚 |
| 齿痕舌 | 舌边有牙齿压痕 | 脾虚湿盛 | 脾虚、湿证 |
| 裂纹舌 | 舌面有裂沟，深浅不一 | 阴血亏虚、脾虚湿浸 | 阴虚、血虚、脾虚 |
| 点刺舌 | 舌面有红点或芒刺 | 热盛、脏腑火炽 | 实热、血热 |
| 瘀斑舌 | 舌面有紫色斑块 | 血瘀 | 瘀血证 |

## 舌形（节选）

齿痕舌是现代人最常见的舌象。十个来看病的，八个有齿痕。教材说齿痕舌主脾虚湿盛，但临床要细分。舌淡胖有齿痕，是脾阳虚，水湿不化；舌红胖有齿痕，是湿热蕴脾；舌瘦薄有齿痕，是气血两虚到了脾虚不能摄血的程度。不能一见齿痕就健脾利湿，红胖的齿痕要清热利湿，瘦薄的齿痕要补气养血。

裂纹舌也很多见。先天裂纹，从小就有，无意义，是生理性的。后天裂纹，阴血亏虚为主。舌红干裂，是阴虚液涸；舌淡白干裂，是血虚不润；舌中裂纹深，是脾胃气阴两伤。很多老年人舌中一道深裂，像峡谷，这是几十年饮食不节、思虑过度，把脾胃的阴液耗干了。

## 舌态总表

| 舌态 | 概念 | 主要病机 | 主病 |
| :--- | :--- | :--- | :--- |
| 强硬舌 | 舌体板硬强直，运动不灵 | 热入心包、中风先兆 | 热极生风、中风 |
| 痿软舌 | 舌体软弱，无力伸缩 | 气血俱虚、阴亏已极 | 气血虚极、阴虚 |
| 颤动舌 | 舌体震颤抖动，不能自主 | 肝风内动 | 热极生风、血虚生风 |
| 歪斜舌 | 伸舌时偏斜一侧 | 肝风夹痰、瘀阻经络 | 中风、中风先兆 |
| 短缩舌 | 舌体紧缩，不能伸长 | 寒凝筋脉、热极生风、痰湿内阻 | 危重证 |
| 吐弄舌 | 舌伸出口外，时时弄舌 | 心脾有热 | 小儿惊风、弱智 |

## 舌态

歪斜舌是中风的预警信号。一个五十岁的人，平时血压高，某天伸舌突然偏左，说话有点含糊，这就是中风先兆，要立即干预。但歪斜舌要分真假。有人天生舌系带过短，伸舌就偏，这是生理性的，不是病。怎么分？让他反复伸舌三次，如果每次都偏同一侧，是病理性；如果有时偏有时不偏，或者偏的方向不固定，可能是习惯性或生理性。

# 五 舌苔变化

## 概念

舌苔是胃气蒸化谷气上潮于舌面而成的苔状物。望舌苔主要观察苔质和苔色两个方面。苔质反映邪正的盛衰和津液的盈亏，苔色反映病邪的性质。

## 苔质总表

| 苔质 | 概念 | 主要病机 | 主病 |
| :--- | :--- | :--- | :--- |
| 薄苔 | 苔质薄，透过舌苔可见舌体 | 胃气充足、病轻邪浅 | 正常、病初期 |
| 厚苔 | 苔质厚，不能透过舌苔见舌体 | 邪盛入里、痰湿食积 | 里证、痰湿、食积 |
| 润苔 | 舌苔润泽有津 | 津液未伤 | 正常、寒证 |
| 燥苔 | 舌苔干燥，扪之无津 | 津液已伤、热盛津伤 | 热盛、阴虚 |
| 滑苔 | 舌苔水分过多，伸舌欲滴 | 寒湿内盛、阳虚水泛 | 寒湿、痰饮 |
| 腻苔 | 苔质致密，颗粒细腻，刮之难去 | 湿浊内蕴、痰饮食积 | 湿浊、痰饮、食积 |
| 腐苔 | 苔质疏松，颗粒粗大，刮之易去 | 阳热有余、胃中腐浊上泛 | 食积、痰浊 |
| 剥苔 | 舌苔部分或全部剥落 | 胃气匮乏、胃阴枯竭 | 胃气虚、胃阴虚 |
| 真苔 | 舌苔紧贴舌面，刮之难去 | 胃气尚存、邪气实 | 病有胃气，预后好 |
| 假苔 | 舌苔松浮，刮之即去 | 胃气衰败、邪气不实 | 病无胃气，预后差 |

## 苔质（节选）

腻苔是现代人最泛滥的舌象。十个里有六七个舌苔厚腻。教材说腻苔主湿浊、痰饮、食积，但临床要分白腻和黄腻。白腻是寒湿或痰饮，黄腻是湿热。很多现代人长期吹空调、喝冷饮、吃肥甘厚味，舌中白腻，这是寒湿困脾。但一见到腻苔就用清热利湿，就错了。白腻要温化，黄腻才清利。

剥苔是胃阴枯竭的信号。舌苔像地图一样一块一块脱落，露出下面的舌质。这叫地图舌，多见于小儿和阴虚体质的成人。小儿地图舌，多是胃阴不足，挑食、偏食、零食吃太多，把胃的阴液耗伤了。成人地图舌，长期熬夜、思虑过度、辛辣刺激，胃阴枯竭。这种舌象，滋阴养胃要缓图，至少三个月。

## 苔色总表

| 苔色 | 概念 | 主要病机 | 主病 |
| :--- | :--- | :--- | :--- |
| 白苔 | 舌苔呈白色 | 表证、寒证 | 风寒、寒湿 |
| 黄苔 | 舌苔呈黄色 | 热证、里证 | 里热、湿热 |
| 灰苔 | 舌苔呈浅黑色 | 热极、寒极 | 里热炽盛、寒湿久郁 |
| 黑苔 | 舌苔呈深黑色 | 热极、寒极、肾亏 | 热极津枯、阳虚寒盛 |

## 苔色

黄苔要分深浅。薄黄是热轻，深黄是热重，焦黄是热极。但黄苔还要看润燥。黄而干燥，是热盛伤津；黄而润滑，是湿热蕴蒸。很多现代人便秘，舌苔黄燥，这是实热在里，通大便就行，大便一通，黄苔自退。但如果是黄腻苔，润滑不干，这是湿热，不能通下，要利湿清热，三仁汤、甘露消毒丹之类。

黑苔是危重信号，但不一定都是死证。热极黑苔，黑而干燥，像锅巴，这是热毒炽盛，津液枯竭，要急下存阴。寒极黑苔，黑而润滑，这是阳虚寒盛，要回阳救逆。还有一种长期抽烟、喝浓茶的人，舌苔染黑，这是染苔，不是病。怎么分？染苔的黑是浮在表面的，刮之即去；病理性黑苔是深入苔质的，刮之不去。

# 六 舌下络脉

## 概念

舌下络脉是舌系带两侧纵行的静脉，反映体内瘀血和阴血的状况。望舌下络脉是舌诊的重要组成部分，尤其对瘀血证的判断有独特价值。

## 观察要点

| 观察维度 | 正常表现 | 异常表现 | 临床意义 |
| :--- | :--- | :--- | :--- |
| 颜色 | 淡紫色或淡红色 | 紫暗、紫黑、紫红 | 紫暗主瘀血，紫黑主瘀血重，紫红主热盛血瘀 |
| 粗细 | 直径不超过7mm | 怒张、迂曲、增粗 | 主瘀血、气滞 |
| 长度 | 不超过舌下肉阜至舌尖的3/| 超过3/5甚至舌尖 | 主瘀血较重 |
| 形态 | 直行或轻度弯曲 | 迂曲如结节、分支多 | 主久病入络、瘀血阻络 |

## 临床意义

舌下络脉紫暗怒张，是体内有瘀血的直接证据。很多心脑血管病人，舌头正面看没什么异常，但舌底一看，两根络脉像蚯蚓一样怒张紫黑。这是瘀血在里的外候。女性痛经、子宫肌瘤，舌下络脉也常紫暗。这种瘀血，单纯活血化瘀不够，要找到瘀血的原因，是气滞、是寒凝、是气虚、是外伤，对因治疗。

# 七 重点难点辨析

## 舌质与舌苔的关系

舌质反映脏腑气血的盛衰，舌苔反映邪气的深浅和胃气的存亡。临床上有"舌质主内，舌苔主外"的说法。但两者要合参。舌红苔黄，是实热；舌红无苔，是阴虚；舌淡苔白，是虚寒；舌淡苔黄，是脾虚湿热。不能只看一个方面。

有根苔与无根苔的鉴别：真苔紧贴舌面，像从舌里长出来的，刮之难去，这是有根，说明胃气还在，病虽重但可救。假苔像撒了一层粉，浮在舌面，刮之即去，这是无根，说明胃气已败，预后差。

## 舌象的动态变化

舌象不是一成不变的，它反映病势的进退。外感病，舌苔由白转黄，由薄转厚，是病邪入里、病情加重。舌苔由黄转白，由厚转薄，是病邪外透、病情好转。内伤病，舌质由红绛转淡红，是阴虚渐复；由淡白转红，是气血渐生。

但有些变化是假象。长期用抗生素的人，舌苔突然剥落，不是病情好转，是胃气被药伤了。化疗病人，舌苔由厚腻突然变无苔，不是湿热退了，是正气被摧毁了。这些动态变化，要结合病史和用药史来判断。

## 现代人体质与舌象的特殊性

现代人舌象有几个普遍偏差，是古人没见过的。

一，齿痕舌泛滥。不是十个有八个，而是城市白领里几乎人人有。因为久坐伤脾，思虑伤脾，冷饮伤脾。脾一虚，水湿不化，舌体胖大，边有齿痕。

二，裂纹舌年轻化。三十岁的人舌中裂纹，古人少见。因为熬夜、辛辣、压力，把胃阴提前耗干了。

三，厚腻苔与剥苔并存。舌中厚腻，舌边剥落，或者前半截有苔，后半截无苔。这是现代人饮食不节、寒热杂进的典型表现。脾被湿困，胃阴又伤，上热下寒，中焦痞塞。

四，舌下络脉紫暗普遍。久坐、少动、压力大，气滞则血瘀。很多二三十岁的人，舌底络脉已经像四五十岁。

这些现代舌象，不能照搬古书。古人见一个齿痕舌，知道是脾虚湿盛，用香砂六君子。现代人齿痕舌背后，可能还有肝郁、还有肾亏、还有血瘀。要综合看，不能单见齿痕就健脾。

# 八 从基础到临床的感悟

## 望舌望的是胃气与血分

望舌，表面看是望一块肌肉，实际上望的是两条线：一条是胃气线，看舌苔；一条是血分线，看舌质。胃气在，舌苔就有根，哪怕厚腻，也还有生机。胃气亡，舌苔剥落或无苔，病就难治了。血分足，舌质淡红柔润；血分亏，舌质淡白或枯红；血分瘀，舌质紫暗。这两条线在舌面上交汇，就是疾病的全貌。

## 现代人舌象的普遍偏差

我门诊看了四十年，近十年最明显的变化是：正常舌象越来越少。淡红舌、薄白苔，这个标准舌象，在年轻人里十难见一。取而代之的是齿痕、裂纹、厚腻、剥苔、络脉紫暗。这不是人种变了，是生活方式变了。久坐、熬夜、冷饮、外卖、压力、抗生素滥用，把脾胃和气血提前透支了。

但现代人又有一个特点：舌象重，症状轻。舌头裂得像峡谷，但他说只是有点累。舌苔厚得像奶油，但他说胃口还行。这是因为现代人的耐受力被训练出来了，或者说麻木了。他习惯了少神的状态，也习惯了偏差的舌象。这时候望舌的价值，是帮他重新看见自己的身体。你把镜子给他，让他看自己的舌头，他可能会惊讶：原来我的舌头已经这样了。

## 不要迷信舌象

舌象重要，但不能迷信。舌象会变，饭前饭后不一样，早上晚上不一样，情绪好坏不一样。一个刚吃完麻辣火锅的人，舌头红得像草莓，你不能说他阴虚火旺。一个刚刮完舌苔的人，舌面光洁无苔，你不能说他胃阴枯竭。所以望舌必须四诊合参，问清楚饮食、用药、作息，再结合脉象、症状，才能定。

还有一种情况，舌象与症状不符。舌质紫暗，应该是瘀血，但病人没有任何疼痛或肿块。这时候要考虑，瘀血是不是在潜在阶段，或者是不是既往外伤留下的痕迹。舌象是静态的，病是动态的，要把舌象放在病程的时间轴上看。

## 望舌最后望的是医者的细致

望舌比望神更需要细致。望神是一眼扫过去，心里就有数。望舌要定下来，看颜色要看准是淡红还是红绛，看舌苔要看准是薄还是厚，看舌下络脉要量粗细、看长度。这需要耐心，也需要经验。一个急躁的医生，伸舌三秒还没看清，就让病人缩回去，漏掉的可能是关键信息。

而且望舌要反复看。一次看是初诊，记在心里。用药一周后，再看一次，对比变化。舌象的变化往往比症状的变化更客观。病人说"还是累"，但你看他舌色从淡白转淡红了，齿痕从深变浅了，这说明气血在恢复，只是他还没感觉到。这种舌象的先行变化，是中医调整用药的重要依据。

以上，就是望舌从基础到深入的全程安排。从舌与五脏的经络联系，到舌面分候地图，到操作规范，到舌质舌苔的分型，再到现代人体质的特殊性，最后落到临床感悟。骨架是教材的，血肉是床边的，中间的操作阶梯和理论衔接，是让基础理论学习者能真正跨进临床的那几步路。
