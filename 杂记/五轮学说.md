## 五轮学说（眼部脏腑分区）

五轮学说是中医望诊的重要部分，将眼睛从外到内分为五个部分（轮），分别对应五脏，以此推断内在脏腑的健康状态。与舌诊的“舌面分部”思路同源，但观察对象和辨证侧重不同。

---

### 一、核心总纲：肝开窍于目，目为肝之外候

1. 整体归属：眼睛的视觉功能、泪液、活动度，首先归属于肝，反映肝血、肝阴、肝气的盛衰。  
   - 肝血足则目能视，肝血虚则目干涩、昏花。  
   - 肝风内动则目斜视、上翻。  

2. 局部五轮：眼睛的五个解剖部位（肉轮、血轮、气轮、风轮、水轮）分别对应脾、心、肺、肝、肾五脏，形成五轮脏腑配属。  

3. 补充：眼与五脏皆通，通过经络联系（如足阳明胃经、手少阴心经等），因此眼部表现能反映多脏腑问题，但以肝为核心。

---

### 二、五轮标准分区（由外向内 → 对应脏腑）

| 轮名 | 解剖部位 | 对应脏腑 | 主要辨证方向 |
|------|----------|----------|--------------|
| 肉轮 | 上下眼睑（眼皮） | 脾、胃 | 脾胃运化、肌肉气血、水湿痰饮 |
| 血轮 | 内外眼角（两眦） | 心、小肠 | 心火、心血、心经实热 |
| 气轮 | 白睛（巩膜、球结膜） | 肺、大肠 | 肺气宣降、外感风热、痰湿、燥邪 |
| 风轮 | 黑睛（角膜、虹膜） | 肝、胆 | 肝火、肝风、肝血虚、肝胆湿热 |
| 水轮 | 瞳孔（及晶状体、玻璃体） | 肾、膀胱 | 肾精盈亏、先天禀赋、水液代谢 |

---

### 三、各轮解析

#### 1. 肉轮（眼睑）—— 属脾

- 正常：眼睑饱满、开合自如、不浮肿、无下垂。  
- 病理倾向：  
  - 脾虚 → 眼睑下垂、松弛、乏力（重症肌无力常见）。  
  - 脾湿 → 眼睑浮肿、眼袋大（水湿停聚）。  
  - 脾热（实热）→ 眼睑红肿、麦粒肿、霰粒肿。  
  - 脾虚血少 → 眼睑色淡、无华。

#### 2. 血轮（两眦）—— 属心

- 正常：内、外眼角红润、无糜烂、无异常分泌物。  
- 病理倾向：  
  - 心火亢盛 → 两眦红赤、疼痛、眼角生疮、眼屎多黄。  
  - 心血虚 → 眼角色淡、干涩。  
  - 心经实热 → 眼角红肿、刺痛、流泪热烫。

#### 3. 气轮（白睛）—— 属肺

- 正常：白睛色白、清亮、无充血、无黄染。  
- 病理倾向：  
  - 肺热（风热犯肺）→ 白睛红赤、结膜充血（红眼病）。  
  - 肺燥津亏 → 白睛干涩、缺乏润泽。  
  - 肺气虚 → 白睛色淡、无力抵御外邪。  
  - 痰湿阻肺 → 白睛混浊、水肿。  
  - 黄疸（肝胆湿热）→ 白睛黄染（需结合风轮）。

#### 4. 风轮（黑睛）—— 属肝

- 正常：黑睛乌黑光亮、透明、无翳膜。  
- 病理倾向：  
  - 肝火上炎 → 黑睛红赤、疼痛、畏光、角膜溃疡。  
  - 肝血虚 → 黑睛失养，暗淡无光，干涩昏花。  
  - 肝阴亏虚 → 黑睛干燥、星点翳膜。  
  - 肝风内动 → 黑睛斜视、上翻、震颤。  
  - 肝胆湿热 → 黑睛生翳（角膜混浊）、黄液上冲。

#### 5. 水轮（瞳孔）—— 属肾

- 正常：瞳孔大小正常、对光反射灵敏、清晰透明。  
- 病理倾向：  
  - 肾精亏虚 → 瞳孔散大、对光反射迟钝、视力下降、白内障、青光眼。  
  - 肾阳虚 → 瞳孔收缩无力、夜盲、视物模糊（视网膜病变）。  
  - 肾水泛溢 → 瞳孔区水肿（如糖尿病视网膜病变）。  
  - 先天不足 → 瞳孔畸形、发育异常。

---

### 四、五轮辨证的核心思路

1. 单一轮病，责其本脏  
   - 眼睑问题（肉轮）→ 先考虑脾。  
   - 两眦红赤（血轮）→ 先考虑心火。  
   - 白睛充血（气轮）→ 先考虑肺热。  
   - 黑睛翳膜（风轮）→ 先考虑肝。  
   - 瞳孔病变（水轮）→ 先考虑肾。

2. 多轮同病，辨脏腑传变  
   - 眼睑浮肿 + 白睛水肿 → 脾肺气虚、水湿不运。  
   - 两眦红赤 + 黑睛生翳 → 心肝火旺。  
   - 白睛黄染 + 黑睛混浊 → 肝胆湿热。  
   - 瞳孔散大 + 视物昏花 + 眼睑下垂 → 肾精亏虚、脾虚气陷。

3. 结合舌诊、脉象、全身症状，不可单凭眼部诊断疾病。

---

### 讲解：五轮学说背后的藏象与经络依据

为什么眼睑归脾？因为脾主肌肉，眼睑是全身最薄的肌肉之一，脾的运化直接决定眼睑的丰满与开合。为什么两眦归心？因为心主血脉，两眦血络丰富，心火亢盛时最先在这里出现红赤。白睛归肺，肺主气、主皮毛，白睛表面的球结膜就像肺的“外皮”，外邪犯肺则白睛充血。黑睛归肝，肝开窍于目，黑睛的透明依赖肝血的濡养和肝气的条达，一旦肝火、肝风，黑睛立刻反应。瞳孔归肾，肾主水、藏精，瞳孔的收缩与精气的盛衰、水液的代谢直接相关，肾精亏则瞳孔开合失度。

另外，五脏与眼睛的经络联系是五轮学说的物质基础：足阳明胃经（脾）连于眼睑；手少阴心经系于两眦；手太阴肺经、足太阳膀胱经等也间接联系白睛；足厥阴肝经直接连目系；足少阴肾经通过脑与目系相通。所以，五轮不是古人随意划分，而是基于实实在在的解剖与经络关联。

### 五、五轮 vs 舌诊：对比总结

| 项目 | 五轮学说（眼） | 舌诊分部（舌） |
|------|----------------|----------------|
| 整体归属 | 肝开窍于目 | 心开窍于舌 |
| 分区依据 | 眼球解剖结构（从外到内） | 舌面方位（上中下、左右） |
| 对应脏腑 | 肉轮→脾，血轮→心，气轮→肺，风轮→肝，水轮→肾 | 舌尖→心肺，舌中→脾胃，舌根→肾膀胱，舌边→肝胆 |
| 辨证侧重 | 肝血、肝火、外感风热、痰湿、肾精 | 脾胃虚实、痰湿、食积、寒热、气血 |
| 优势病种 | 眼科疾病、肝病、神经病变、先天不足 | 消化系统疾病、代谢病（痰湿）、感染性疾病 |
| 观察时机 | 自然光下，无需特殊准备 | 晨起空腹、刷牙前最佳 |
| 变化速度 | 慢性病较慢，急性感染/过敏较快 | 舌苔变化快（日或数日），舌质变化慢（周或月） |

### 六、日常自查简易流程（五轮）

1. 自然光下，面对镜子，放松平视。  
2. 观察顺序：  
   - 先看眼睑（肉轮）：有无浮肿、下垂、色淡、红肿、麦粒肿？  
   - 再看两眦（血轮）：有无红赤、糜烂、眼屎？  
   - 然后白睛（气轮）：是否充血、黄染、干涩、水肿？  
   - 接着黑睛（风轮）：是否透亮、有无翳膜、溃疡？  
   - 最后瞳孔（水轮）：大小是否正常、对光反应？  
3. 结合全身：是否伴有眼干、眼胀、视力模糊、畏光、流泪等。  

---

###  讲解：五轮与舌诊联合应用的临床案例

案例一（脾虚湿盛）  
患者晨起眼睑浮肿（肉轮），同时舌体胖大、齿痕、苔白厚腻。五轮与舌诊都指向脾虚、水湿不运。用参苓白术散健脾祛湿一周后，眼睑浮肿减轻，舌苔变薄。

案例二（肝火上炎）  
患者两目红赤、黑睛生翳（风轮），同时舌边红、苔黄、脉弦数。五轮显示肝火，舌诊佐证肝胆火旺。用龙胆泻肝汤清肝泻火，三天后红赤消退，舌边红转淡。

案例三（心肾不交）  
患者两眦淡红不肿，但瞳孔对光反应迟钝、夜盲，同时舌尖红少苔、舌根裂纹。五轮提示肾精亏（水轮）+心火偏亢（血轮淡红为虚火），舌诊也支持心肾不交。用天王补心丹合六味地黄丸，调理一个月后视力改善，睡眠好转。

这些案例说明：五轮与舌诊结合，能更精准定位病位、判断病性，避免单一方法的片面性。

---

### 七、与舌诊联合使用的价值

- 眼、舌互参：  
  - 脾虚湿盛 → 眼睑浮肿（肉轮） + 舌胖大齿痕、舌苔厚腻。  
  - 肝火上炎 → 黑睛红赤（风轮） + 舌边红、苔黄。  
  - 心火亢盛 → 两眦红赤（血轮） + 舌尖红、口舌生疮。  
  - 肾精亏虚 → 瞳孔散大（水轮） + 舌根瘦小、裂纹、少苔。  

- 动态跟踪调理效果：  
  - 健脾祛湿后，眼睑浮肿消退、舌苔变薄 → 有效。  
  - 清肝泻火后，黑睛红赤减轻、舌边红转淡 → 有效。  

---

### 八、总结

1. 五轮学说与舌诊分部同为中医局部望诊精华，逻辑一致：通过外显部位推断内在脏腑。  
2. 眼以肝为总司，按解剖部位分属五脏；舌以心为总司，按方位分属五脏。  
3. 五轮对肝血、肝火、外感、肾精判断更有优势；舌诊对脾胃、痰湿、寒热、气血更精细。  
4. 日常自查：两者结合使用，能更全面把握体质状态和调理进度。  
5. 记住：单一表现仅作倾向参考，四诊合参才是诊断正道。
